# Project collaboration

- Preserve the existing feature, domain, service and mock-data boundaries.
- Keep database-backed seed content in `src/mocks/data`.
- Commit or push changes only when the user explicitly instructs you to do so. Do not automatically commit routine edits.
- The project repository is `https://github.com/FeiswalDindi/yerh.git`.
- Use `npm run check` for application changes and `npm run format:check` for formatting validation.
- Keep dependencies, build output, runtime logs, local archives and private environment files out of Git. `.env.example` is the safe configuration template.
